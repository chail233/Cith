## 2. recall() 查询流水线

```mermaid
flowchart LR
    Q["query 文本"] --> QE["embed + L2归一化"]
    Q --> QENT["查询侧实体抽取<br/>（graph:true 时）"]
    QE --> POOL{"候选池选择"}
    POOL -->|"filtered(tag/日期) 或 &lt;1000条"| SCAN["全量扫描 records[]"]
    POOL -->|否则| TOPK["HNSW search<br/>k = max(limit×8, 64), ef=200"]
    TOPK --> UNION["∪ 实体关联记忆<br/>（图可救回低相似度连接）"]
    SCAN --> R
    UNION --> R["逐条评分"]
    QENT --> R
    R --> F1{"原始 cosine &lt; minSimilarity<br/>且无共享实体?"}
    F1 -->|是| DROP["丢弃"]
    F1 -->|否| CALC["score = (cos + min(0.3, 0.1×共享实体数)<br/>+ signed log阻尼hardening ≤±0.15)<br/>× importance × 半衰期衰减<br/>（锚点 = reinforcedAt ?? createdAt）"]
    CALC --> SORT["按 score 降序 → 截断 limit"]
    SORT --> HITS["RecallHit[]<br/>含 score / similarity / sharedEntities"]
```

## 3. 反馈闭环（防自强化设计）

```mermaid
sequenceDiagram
    participant A as Agent
    participant M as Memory(rememori)
    participant L as LLM

    A->>M: recall(query, {halfLifeDays})
    M-->>A: hits[]（候选）
    A->>L: system prompt ← hits文本
    L-->>A: output（回答）
    A->>M: reinforceFromOutput(hits, output)
    Note over M: 证据门控：仅当记忆文本<br/>被逐字引用/高包含率<br/>且数字全部一致<br/>才 reinforce —— 避免<br/>"模型自称用了→自己加权"的<br/>surfacing feedback loop
    M->>M: 命中的id：reinforcements+1,<br/>reinforcedAt=now（衰减锚点重置）
    A->>M: remember(新信息)
    A->>M: collisions(newId)
    M-->>A: 邻近记忆（cosine≥0.8）
    A->>L: 裁决 duplicate / update / contradiction
    L-->>A:  verdict
    A->>M: demote(败方) 或 forget(重复)
    Note over M: demote→reinforcements−1（可为负），<br/>立即降权而非等衰减；<br/>罚过头直接掉出召回（有意，有测试锁定）
```

## 4. 关键常量速查（src/memory.ts）

| 常量 | 值 | 含义 |
|---|---|---|
| `ENTITY_BONUS` / `CAP` | 0.1 / 0.3 | 每共享实体加成 / 封顶 |
| `HARDENING_STEP` / `CAP` | 0.05 / 0.15 | log2 阻尼反馈步长 / 封顶（正负对称） |
| `HNSW_AUTO_THRESHOLD` | 1000 | 超过则 auto 模式切 HNSW |
| `HNSW_REBUILD_RATIO` | 0.2 | tombstone 占比超过即重建索引 |
| `minRun` / `minContainment` | 4 / 0.6 | 证据门控阈值（evidence.ts，可调） |
| `collisions threshold` | 0.8 | 近邻判定 cosine 阈值 |

## 5. 设计上刻意"不做"的事

- **不做服务端/托管**：嵌入式原语，数据 = 单个本地 JSONL 文件
- **不在引擎内裁决矛盾**：embeddings 对矛盾句几乎同分，语义判断交上层 LLM
- **证据检测刻意不用 embedding**：防止反馈回路软性复活
- **recall 是纯读**：不自动强化——加权必须来自排序体系之外的显式信号
